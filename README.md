## 🧐 About the Project

We include test of Adam vs minSR on four different hamiltoninans; 1D TFIM, 1D Cluster state, 2D Heisenberg, 2D frustrated J1-J2

### Key Features

- 🚀 **Feature 1**: Adaptive learning rates.
- ⚡ **Feature 2**: Tuned Hyperparemeters.
- 🛡️ **Feature 3**: Adaptive damping with Levenberg-Marquadt.
