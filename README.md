# RNN-Natural-Gradients
Repository to reproduce results in X. Under construction!

> *Comparing minSR and Adam on RNN Wavefunctions.*


## 🧐 About the Project

We include test of Adam vs minSR on four different hamiltoninans; 1D TFIM, 1D Cluster state, 2D Heisenberg, 2D frustrated J1-J2

### Key Features

- 🚀 **Feature 1**: Adaptive learning rates.
- ⚡ **Feature 2**: Tuned Hyperparemeters.
- 🛡️ **Feature 3**: Adaptive damping with Levenberg-Marquadt.

### Built With

Python, Jax, Flax


---

## 🚀 Getting Started

To run the code use:

```
python Scripts/Heisenberg2D.py 0 [-t]
```

For testing locally use [-t] flag


### Prerequisites

To import packages run
```
pip install -r requirements.txt
```
